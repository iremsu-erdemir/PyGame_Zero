## Oyun Hakkında

- **Oyunun Türü:** Platformer / Runner
- **Amaç:** Oyuncu engellerden ve düşmanlardan kaçarak seviyenin sonundaki hedefe ulaşmaya çalışır.
- **Kaybetme Koşulu:** Oyuncu düşmana çarparsa veya platformdan düşerse oyun sona erer.
- **Kazanma Koşulu:** Seviyenin sonundaki bayrağa veya kapıya ulaşılırsa oyun kazanılır.
- **Kontroller:**
  - ⬅️ Sol Ok / A : Sola hareket
  - ➡️ Sağ Ok / D : Sağa hareket
  - ⬆️ Yukarı Ok / Space : Zıplama
- **Ses Özellikleri:**
  - Arka plan müziğini açma/kapatma
  - Coin toplama sesi
  - Düşmana çarpma/oyun bitiş sesi
